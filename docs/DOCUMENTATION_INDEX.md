Updated: 31 October 2026. This index separates current product guidance, developer references and historical records. Older version numbers, proposed stacks and test counts do not establish today's implementation or release status.

## Read first

1. [Core objective](CORE_OBJECTIVE.md): the product, intended daily workflow and decisive acceptance milestone.
2. [Product direction](PRODUCT_DIRECTION.md): the owner's preserved request, corrections and priority order.
3. [README](../README.md): current entry point and how to try the source or preview.
4. [Readiness](READINESS_V0_9.md): what exists, what has evidence, and what remains open.
5. [Next sprints](NEXT_SPRINTS.md) and [complete backlog](PRODUCT_BACKLOG.md): implementation order and remaining work.
6. [Handoff](HANDOFF.md), [architecture](ARCHITECTURE_V0_9.md) and [test report](TEST_REPORT_V0_9.md): continuation details and dated evidence.

## Reading rules

- The objective and direction define the target. Readiness and dated test reports define observed implementation and acceptance.
- Current Windows work uses WinForms plus the existing private Node service. The Tauri host is a separate experiment, not the present compiled Windows UI.
- Historical records keep their original results and dates. An earlier setup result does not validate a later binary; an old blocked test is not a new failure.
- Research references retain their original consultation dates. This documentation refresh did not repeat competitor, platform, legal or provider research.
- All paths below refer to repository documentation. Generated packages, real vaults and local reports are not part of the source distribution.
