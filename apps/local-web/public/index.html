WORKSPACE CONTROL

Privacy & settings

Your vault is designed for explicit control, local-first use, and limited resource consumption.

♧

Local encrypted vault

Stored as AES-256-GCM encrypted records in SQLite. Metadata and the SQLite file structure are not fully encrypted.

Data lives in your local data directory. Keep the complete vault folder, including keyinfo.json, for recovery. The key file now contains the wrapped archive key.
⊘

Capture is opt-in

The browser companion can observe known AI composers after per-site approval. It does not record all applications or your clipboard.

Native capture will require separate consent, OS permissions, exclusions, and per-app verification.
◌

Cloud AI is optional

The app serves assets and API requests only on 127.0.0.1, with per-session authorization.

No trackers or cloud sync. Groq requests require a locally configured key, a preview and explicit consent.
◷

Automatic lock

The local session locks after 15 minutes without authenticated activity.

Close the terminal to stop the local service. Back up the vault files before upgrading.
